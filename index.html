Agent Observe Skill scans local code for Vercel AI SDK patterns—prompts, tools, model calls, and chains—plus API routes, client entry points, eval gaps, and trace risks.

Your code stays local.
The scanner writes Markdown, JSON, and a simple visual report into .agent-observe-skill/.
View demo

Use with Codex

Install the scanner as a repo-local skill or from the Codex Plugin Directory.

Repo-local skill

From the repo you want to scan, install into .agents/skills, then restart Codex from that same checkout and start a new thread.

Codex plugin

Add the marketplace catalog. This does not enable the skill by itself; after restart, install Agent Observe Skill from Plugin Directory and start a new thread.

After install, ask Codex:

Use $agent-observe-skill to scan this repo.

Install with Claude Code

Use the skills.sh CLI, then invoke the skill from Claude Code.

After install, ask Claude Code:

Use $agent-observe-skill to scan this repo.

Prompts and model calls

Find inline prompts, system messages, Vercel AI SDK calls, OpenAI SDK calls, and chain steps.

Tools and routes

Map tool schemas, execute handlers, side effects, API routes, and UI entry points.

Risks and gaps

Flag chains without evals, trace IDs, structured logging, or durable telemetry.
