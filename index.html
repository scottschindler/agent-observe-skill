Agent Observe Skill Local observability for agent code.

See every prompt, tool, and chain in your repo.

Agent Observe Skill scans local code for AI SDK calls, tool schemas, API routes, client entry points, eval gaps, and trace risks.

Your code stays local. The scanner writes Markdown, JSON, and a simple visual report into .agent-observe-skill/.

View demo

Install with Codex

Add the marketplace once, restart Codex, then install Agent Observe Skill.

codex plugin marketplace add scottschindler/agent-observe-skill --sparse .agents/plugins

Install with Claude Code

Use the skills.sh CLI, then invoke the skill from Claude Code.

npx skills add scottschindler/agent-observe-skill

Prompts and model calls

Find inline prompts, system messages, stream calls, generated objects, and chain steps.

Tools and routes

Map tool schemas, execute handlers, side effects, API routes, and UI entry points.

Risks and gaps

Flag chains without evals, trace IDs, structured logging, or durable telemetry.
