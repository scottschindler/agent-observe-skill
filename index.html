Agent Observe Skill Local observability for agent code.

See every prompt, tool, and chain in your repo.

Agent Observe Skill scans local code for AI SDK calls, tool schemas, API routes, client entry points, eval gaps, and trace risks.

Your code stays local. The scanner writes Markdown, JSON, and a simple visual report into .agent-observe-skill/.
